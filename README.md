### bots basic to setup
- run `npm install` and then run `node index.js` your bots now up and running you may also set this up to use pm2 of course [pm2.io](https://pm2.io/)

### Commands
```
/register – Register your server
/setmessage – Set partner message
/setchannel – Set bump channel
/unregister – Remove server from partner list
/bump – Broadcast your message (30-minute cooldown)
/setinvite – Set your server invite link
/invite – Get bot invite
/help – View this page
```
